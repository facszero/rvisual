## Update: rvisual 0.3.0

This is an update of rvisual 0.1.1 (currently on CRAN).

Main changes (see NEWS.md):

* New "Modelado (ML)" panel: a guided supervised machine learning assistant
  (regression and classification, cross-validation, final model, predictions
  on new data) that writes a self-contained, reproducible R script. All
  machine learning packages (rpart, glmnet, ranger, xgboost, pROC) are in
  Suggests and are only used if installed; tests skip when they are missing.
* Bug fixes in the visual query builder (joins, filters on text codes,
  columns created by previous steps) and in the database panel.
* The AI assistant can store API keys in the operating system keyring
  through the optional 'keyring' package (Suggests).
* NAMESPACE is now fully generated by roxygen2. The exported API is
  unchanged: only launch_rvisual().

## Notes for CRAN

* The package does not write to the user's home directory, the working
  directory or the global environment unless the user asks for it in the
  app (exporting files, choosing a working directory with an explicit
  button, or running generated code in the console after a confirmation
  dialog). Configuration is stored under tools::R_user_dir("rvisual").
* launch_rvisual() raises shiny.maxRequestSize while the app is open and
  restores the user's value on exit.
* Examples are wrapped in \dontrun{} because launch_rvisual() opens an
  interactive Shiny gadget.
